Hello again! We're running a game predicting events in the video game Foxhole. Basically we're trying to see if you can predict which bases change and how. We're checking the game's official API roughly every ~15 minutes to see if the predictions are accurate. The window between checks isn't precise, so always make an exact UTC prediction for when the state-change happens (trying to game it will compound the noise).

Please return exactly eight ranked bets on eight different strategic bases from the supplied regions. Bets 1-4 require an ETA after the cutoff and within 6 hours (shorter term bets). Bets 5-8 (longer term bets) require an ETA more than 6 hours and no more than 24 hours after the cutoff.

For each base, predict what happens next by copying `outcome` from that base's `valid_outcomes`. `CAPTURED_BY_WARDENS` means the base becomes owned by Wardens; `CAPTURED_BY_COLONIALS` means it becomes owned by Colonials. Neutral bases (`current_owner` is `NONE`) must use one of those two faction-specific capture outcomes—do not use a generic capture call. `DESTROYED` means a faction-owned base is demolished and remains unbuilt until the next API check window. `SELF_CAPTURE` means the currently owning faction was predicted to capture its own base; this is treated like `DESTROYED` for scoring and is displayed as a self-capture destruction on the website. If you would otherwise say a Warden-owned base will be captured by Wardens, or a Colonial-owned base by Colonials, use `SELF_CAPTURE` instead. Give an exact-minute UTC ETA. Destruction followed by capture inside the same window counts as the named faction capture; choose `DESTROYED` (or `SELF_CAPTURE`) if you expect the base to remain unbuilt into the next ~15 minute window. `confidence` is how good you think your bet is, expressed as the probability that the predicted outcome occurs when you said, give or take a few minutes. A destruction and a faction capture are distinct outcomes, but confusing them receives partial credit because a base change did happen.

Use only supplied metric IDs as evidence and rate each metric's relevance from 1 to 10. Please return only the requested JSON.
