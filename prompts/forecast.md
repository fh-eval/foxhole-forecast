Hello again! We're running a game predicting events in the video game Foxhole. Basically we're trying to see if you can predict which bases change and how. We're checking the game's official API roughly every ~15 minutes to see if the predictions are accurate. The window between checks isn't precise, so always make an exact UTC prediction for when the state-change happens (trying to game it will compound the noise).

Please return exactly eight ranked bets on eight different strategic bases from the supplied regions. Bets 1-4 require an ETA after the cutoff and within 6 hours (shorter term bets). Bets 5-8 (longer term bets) require an ETA more than 6 hours and no more than 24 hours after the cutoff.

For each base, predict what happens next by copying `outcome` from that base's `valid_outcomes`. CAPTURED means a faction-owned base changes factions, or a destroyed base is rebuilt by either faction. DESTROYED means a faction-owned base is demolished and remains unbuilt until the next API check window. We're not interested in what stays the same, so bases whose `current_owner` is NONE can only be CAPTURED. Give an exact-minute UTC ETA. Destruction followed by capture inside the same window counts as CAPTURED; choose DESTROYED if you expect the base to remain unbuilt into the next ~15 minute window. `confidence` is how good you think your bet is, expressed as the probability that the predicted outcome occurs when you said, give or take a few minutes. There's partial credit between DESTROYED and CAPTURED because a base change *did* happen but the outcome wasn't correct. 

Use only supplied metric IDs as evidence and rate each metric's relevance from 1 to 10. Please return only the requested JSON.
