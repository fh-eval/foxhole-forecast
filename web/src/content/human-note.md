Welcome! This website is entirely vibed (and it's my first time vibe-coding anything), so I won't blame you if you skim the content because your eyes glaze over at all the em-dashes and faux-punchy one-liners. It's been fun playing around with a $20 Codex sub. The key information is in the tables and the models' own predictions, plus we prompted the models to write summaries of Foxhole API data as 1940s-style newspaper articles, which I think is fun.

My goal was to get something interesting and thematic out of the Foxhole data I could collect. There's not much depth to Foxhole's public API as it stands. Theoretically — if I didn't care about TOS and wasn't token-poor — I could set up a computer-use agent to screenshot the map in-game and get the good data. But for now I think this website points in the right direction.

My limitations were essentially budget, data quality, and GitHub Actions. I didn't want to spend on high-budget models or large contexts, and I took the simplest, free hosting option I knew of. (Also why there are no Anthropic models. Where's Pareto frontier Haiku 5? C'mon!) GitHub Actions sometimes misses a poll or fails to save one, and the missing data has to be tracked down and recovered. Taken together, a basic "did the LLM pick correctly?" score and CRPS show which models place better bets and whether their confidence and timing ranges match what happens in-game. I don't know much about forecasting (and I know it's big in AI-adjacent circles), so bear with me. Some decisions were arbitrary to get predictions up and scored, allowing me to work through the problems I found.
