Welcome! This website is entirely vibed (and it's my first vibe-coded anything) so I won't blame you if you skim the content & your eyes glaze over at all the em-dashes and faux-punchy one-liners. It's been fun playing around with a $20 codex sub and I learned a lot. The key information is in the tables and the model's own predictions, plus we prompted the models to write summaries of Foxhole API data as 1940s style newspaper articles which I think is fun. I don't really know much about forecasting at all, so some decisions are arbitrary so I can get predictions up and scored. 

I'm treating this like a proof of concept where the goal is to get Foxhole data and have the models do interesting things with it, while keeping it thematic & fun. There's not much depth to Foxhole's public API and theoretically (if I didn't care about TOS and wasn't token-poor), I could set up a computer-use agent to screenshot the map in-game and get the good data. But for now I think this website gives you a pretty good idea of what I want to do except with better data if I can get ahold of it.
