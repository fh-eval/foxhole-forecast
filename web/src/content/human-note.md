Welcome! This website is entirely vibed (and my first time vibe-coding) so I won't blame you if you skim the content & your eyes glaze over at all the em-dashes and faux-punchy one-liners. It's been fun playing around with a $20 codex sub and I learned a lot. The key information is in the tables and the models' own predictions, plus we prompted the models to write summaries of Foxhole API data as 1940s-style newspaper articles which I think is fun. I don't really know much about forecasting at all, so some decisions are arbitrary so I can get predictions up and scored. 

My goal was to get Foxhole data and have the models do interesting things with it, while keeping it thematic and fun. There's not much depth to Foxhole's public API and theoretically (if I didn't care about TOS and wasn't token-poor), I could set up a computer-use agent to screenshot the map in-game and get the good data. But for now I think this website gives you a pretty good idea of what I want to do but with better data if I can get ahold of it.

My limitations were essentially budget, data quality, and GitHub Actions. I didn't want to spend on high-budget models or growing contexts, and took the simplest, free hosting option I knew of. GitHub Actions sometimes misses or fails to save a poll, which needs to be tracked down and recovered. As it is, between a basic "did the LLM pick correctly?" score and CRPS, you can see which models are better at placing correct bets and their claimed uncertainty.
